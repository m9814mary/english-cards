Block 01

I heard that last week's local fight might have been fixed, so I decided on watching a different event instead. I just hope for a fair match next time.

先週の地元の格闘技イベントは八百長だったかもしれないと聞いたので、今回は別のイベントを見ることに決めた。次回は公正な試合であってほしいと願っている。

意味：試合・結果などを八百長にする

ニュアンス：修理とは全く別の口語的な意味

意味：複数の選択肢から最終的に一つを選び取る

ニュアンス：最頻出パターン

hope for ~ ［hope］

意味：〜を望む・期待する

ニュアンス：具体的な対象に向けて願う基本形

配達員は自分で休憩時間を選ぶことが許可されているので、公園の近くで短い休憩を取ることに決めた。結局、自分のために食事を注文しないことに決めた。

意味：〜することが許可されている

fix on ~ ［fix］

意味：〜に決める・〜に焦点を当てる

ニュアンス：選択の決定

decide against ~ ［decide］

意味：〜しないことに決める

ニュアンス：一度検討した選択肢を不採用にする

うまくいけば雨はすぐ止むだろう。配達会社が夜のシフトを中止するかもしれないからだ。念のため、私はいつも余分な時間を見込んでおくようにしている。

hopefully ［hope］

call off ［cancel］

意味：予定・計画を中止する

ニュアンス：cancelとほぼ同義だが口語的

allow for ~ ［allow］

意味：〜を考慮に入れる・見込む

ニュアンス：「許可する」とは別の意味

語彙注釈（準2級以上）shift (名詞) シフト・勤務時間 準2級
